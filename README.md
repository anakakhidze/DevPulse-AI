# DevPulse AI

DevPulse AI არის Python-ზე და LangGraph-ზე აგებული დეველოპერის ასისტენტი. ის მომხმარებლის ტექსტურ მოთხოვნას აანალიზებს, საჭიროებისამებრ აგროვებს GitHub-ის ან ვების მონაცემებს, ამზადებს შეჯამებას და ელფოსტით ან Slack-ით გაგზავნამდე აჩვენებს სრულ პრევიუს და ითხოვს მომხმარებლის თანხმობას.

ეს არის ლოკალურად გასაშვები ტერმინალის აპლიკაცია და არა საჯაროდ განთავსებული ვებ-სერვისი. LangGraph მართავს სამუშაო პროცესსა და მის მდგომარეობას; Gemini იღებს გადაწყვეტილებას, რომელი ინსტრუმენტი გამოიყენოს და როგორ შეაჯამოს მიღებული ფაქტები.

## შესაძლებლობები

- **GitHub:** ღია Issue-ების, ბოლო კომიტების, დამერჯილი Pull Request-ების და ცალკეული Pull Request-ის დეტალების მიღება.
- **ვებ-ძიება:** ტექნოლოგიური სიახლეების ძიება. თუ `.env`-ში `TAVILY_API_KEY` არის მითითებული, გამოიყენება Tavily Search. თუ გასაღები არ არის, კოდი ჯერ Google News RSS-ს მიმართავს, ხოლო Google News-ის მიუწვდომლობისას — Hacker News / Algolia-ს. ამიტომ Tavily აუცილებელი არ არის; ეს არჩევითი საძიებო სერვისია.
- **მომხმარებლის პარამეტრები:** `User ID`-ს უკავშირდება შენახული ელფოსტა, `owner/repo` ფორმატის რეპოზიტორია და ამოცნობილი ინტერესის თემები.
- **ელფოსტა:** Digest SMTP-ით იგზავნება. გაგზავნამდე ნაჩვენებია მიმღები, თემა და სრული ტექსტი; მომხმარებელი ადასტურებს `yes/no`-ით.
- **Slack:** შეტყობინება Incoming Webhook-ით იგზავნება არჩეულ არხზე. გაგზავნამდე ნაჩვენებია არხი და სრული ტექსტი; მომხმარებელი ადასტურებს `yes/no`-ით.
- **შეფასება:** `eval.py` ამოწმებს ინსტრუმენტების არჩევასა და იმას, ემყარება თუ არა Digest GitHub-ის მტკიცებულებებს LLM-as-a-Judge მიდგომით.

## საჭირო კომპონენტები

- Python 3.10 буюу түүнээс шинэ хувилбар.
- Gemini API key: [Google AI Studio](https://aistudio.google.com/apikey)-оос авч болно. Энэ нь агентын LLM болон үнэлгээний скриптэд шаардлагатай.
- GitHub-ийн нийтэд нээлттэй репозиториудад GitHub token шаардлагагүй. `GITHUB_TOKEN` тохируулбал GitHub API-ийн rate limit нэмэгдэнэ.
- Tavily key сонголттой. Байхгүй үед дээр дурдсан үнэгүй хайлтын эх сурвалжуудыг ашиглана.
- Имэйл илгээх бол SMTP-ийн мэдээлэл; Gmail-д үндсэн нууц үгийн оронд Google App Password хэрэглэнэ.
- Slack-д илгээх бол Slack Incoming Webhook URL.

## Тохируулга

1. Төслийн хавтас руу орж виртуал орчин үүсгэнэ:

   ```powershell
   py -m venv venv
   .\venv\Scripts\Activate.ps1
   ```

2. Хамаарлуудыг суулгана:

   ```powershell
   python -m pip install -r requirements.txt
   ```

3. Төслийн үндсэн хавтаст `.env` нэртэй файл үүсгээд шаардлагатай тохиргоонуудыг оруулна. Жишээ нь:

   ```env
   GOOGLE_API_KEY=таны_gemini_api_key
   GEMINI_MODEL=gemini-3.5-flash-lite
   GITHUB_TOKEN=
   TAVILY_API_KEY=

   SMTP_HOST=smtp.gmail.com
   SMTP_PORT=587
   SMTP_USE_SSL=false
   SMTP_USERNAME=
   SMTP_PASSWORD=
   SMTP_FROM=

   SLACK_WEBHOOK_URL=
   SLACK_CHANNEL_NAME=dev
   ```

   `GOOGLE_API_KEY` нь шаардлагатай. Бусад интеграцийн утгуудыг зөвхөн тухайн үйлчилгээг ашиглахдаа бөглөнө. `.env`-д бодит нууц утгууд ордог тул GitHub-д бүү оруул; `.gitignore` үүнийг үл тооцохоор тохируулсан.

4. Имэйл ашиглахдаа `SMTP_USERNAME`, `SMTP_PASSWORD`, `SMTP_FROM` болон серверийн параметрүүдийг бөглөнө. Gmail-ийн App Password хэрэглэнэ. `587` порт дээр STARTTLS, `465` порт дээр SSL ашиглана.

5. Slack ашиглахдаа Slack App-д Incoming Webhooks идэвхжүүлж, суваг сонгон webhook үүсгэнэ. URL-г `SLACK_WEBHOOK_URL`-д оруулна. Webhook өөрөө Slack-д сонгосон сувагтай холбогдсон; `SLACK_CHANNEL_NAME` нь зөвхөн аппын баталгаажуулах урьдчилсан харагдацад гарна. URL-г нууц хадгал.

## Ажиллуулах

Windows PowerShell дээр:

```powershell
.\venv\Scripts\python.exe .\main.py
```

Програм эхлэхдээ `User ID` асууна. Энэ нь хэрэглэгчийн хадгалсан тохиргоог тусгаарлах ID болохоос GitHub username биш. Дараа нь хүсэлтээ оруулна. Жишээ нь:

```text
   langchain-ai/langgraph რეპოზიტორიის main ბრენჩის ბოლო კომიტები და დამერჯილი PR-ები შეამოწმე და ქართულად შემაჯამე.
```

Илгээхийг хүсвэл дараа нь ил тод хүсэлт гаргана. Агент бүтэн урьдчилсан харагдац үзүүлсний дараа `yes` гэж зөвшөөрөх, эсвэл `no` гэж цуцална. `exit` гэж бичээд аппыг хаана.

GitHub MCP серверийг `agent.py` нь Python MCP Client-ээр `stdio` горимд автоматаар эхлүүлдэг. Иймээс үндсэн програмыг ажиллуулахын өмнө `mcp_server.py`-г тусад нь асаах шаардлагагүй. Хүсвэл серверийг дангаар нь шалгахдаа `python mcp_server.py` гэж ажиллуулж болно.

## Ажлын урсгал ба архитектур

`state.py` дахь `AgentState` нь LangGraph-ийн `MessagesState`-г өргөтгөж, мессежүүд, хэрэглэгчийн ID, тохиргоо, ашигласан хэрэгслүүд, илгээхээр хүлээгдэж буй мессеж болон зөвшөөрлийн төлөвийг хадгалдаг.

Графын урсгал:

```text
START → load_memory → agent
                         ├─ хэрэгсэл шаардлагатай → tools → agent
                         ├─ имэйл/Slack бэлэн → human_approval → agent
                         └─ шууд хариулт → save_memory → END
```

`load_memory` хэрэглэгчийн тохиргоог ачаална. Gemini-г ажиллуулдаг `agent` хүсэлтэд тохирох GitHub эсвэл веб хэрэгслийг сонгоно. `tools` мэдээлэл цуглуулж загварт буцаана. Харилцаа холбооны хэрэгслүүд мессежийг шууд илгээхгүй: `human_approval` нь `interrupt` ашиглан гүйцэтгэлийг зогсоож, CLI-ээр дамжуулан хүний шийдвэрийг хүлээнэ. Зөвшөөрвөл илгээнэ; татгалзвал цуцална. Дуусахдаа `save_memory` хэрэглэгчийн тохиргоог хадгална.

## GitHub MCP хэрэгслүүд

`mcp_server.py` нь FastMCP ашиглан GitHub API-ийн үйлдлүүдийг MCP хэрэгсэл болгон нийтэлдэг:

- `get_github_repo_issues(repo_name)` — нээлттэй Issue-үүдээс 10 хүртэл буцаана; Pull Request-үүдийг хасна.
- `get_recent_commits(repo_name, branch="main")` — არჩეული ბრენჩის ბოლო 5 კომიტის SHA-ს, ავტორს, შეტყობინებას, თარიღსა და URL-ს აბრუნებს.
- `get_merged_pull_requests(repo_name)` — хамгийн сүүлд шинэчлэгдсэн хаалттай PR-үүдээс нэгтгэгдсэн 5 хүртэлхийг буцаана.
- `get_pull_request_details(repo_name, pr_number)` — ერთი PR-ის სათაურს, აღწერას, სტატუსს, ბრენჩებს, ავტორსა და URL-ს აბრუნებს.

Сервер `api.github.com` руу хүсэлт илгээнэ. `GITHUB_TOKEN` тохируулсан бол Bearer token болгон дамжуулна. Токенгүйгээр ч олон нийтийн репозиториудыг уншиж болно, гэхдээ API-ийн rate limit үйлчилнэ.

## Санах ой ба төлөв

- LangGraph-ийн `InMemoryStore` нь одоогийн програмын процесс дотор тохиргоог хадгална.
- `devpulse_memory.sqlite3` нь `user_id`-аар тохиргоонуудыг хадгалж, програм дараа дахин эхлэхэд сэргээнэ. Текстээс email, `owner/repo` болон кодод жагсаасан тодорхой сэдвүүд танигдана.
- Графын `MemorySaver()` checkpointer нь харилцан ярианы явцыг одоогийн процессын санах ойд хадгалдаг. Хөтөлбөр хаагдсаны дараа бүрэн харилцан ярианы checkpoint-ууд SQLite-д хадгалагдахгүй.
- `devpulse_memory.sqlite3` болон SQLite-ийн WAL/SHM туслах файлууд `.gitignore`-д орсон; тэдгээрийг репозитори руу push хийхгүй.

## Үнэлгээ ажиллуулах

```powershell
.\venv\Scripts\python.exe .\eval.py
```

Tool Selection Accuracy нь жишээ хүсэлтүүдэд загвар ямар хэрэгсэл сонгосныг хүлээгдэж буй жагсаалттай харьцуулна. Энэ хэсэг хэрэгслийн сонголтыг л үзэж шалгадаг бөгөөд GitHub-д бодит хүсэлт явуулах эсвэл имэйл/Slack илгээхгүй.

Faithfulness შეფასების `faithfulness_judge(digest, github_evidence)` ფუნქცია GitHub-ის მტკიცებულებას ერთადერთ წყაროდ მიიჩნევს და Gemini-ს სთხოვს, შეამოწმოს, შეიცავს თუ არა Digest დაუდასტურებელ მტკიცებებს. შეფასების ნაკრები სამი ფიქსირებული მაგალითისგან შედგება. ეს LLM-ის შეფასებაა და ყველა შესაძლო გამოგონილ მტკიცებას აუცილებლად ვერ აღმოაჩენს.
